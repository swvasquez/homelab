# README conventions

- State that the code was generated with AI assistance, and do it at the top —
  in the opening block before the first section heading, so a reader sees it
  before anything else. Name no provider, model, or tool: "AI assistance" and
  nothing more specific.
- Don't restate the `inventory.yml` or `group_vars` schema here. It lives in
  `docs/configuration.md`; the Setup section links to it.
